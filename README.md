# Exam Mistake Tracker

A study app for keeping practice exams, question screenshots, mistakes and review together.

[Download the latest Windows version](https://github.com/sebmansfield/exam-mistake-tracker-downloads/releases/latest)

## Install

1. Open the latest release and download **Exam-Mistake-Tracker-V10-Setup.exe**.
2. Run setup. It downloads and verifies the full desktop application, then opens the installation wizard.
3. Launch Exam Mistake Tracker from its shortcut.

Requires 64-bit Windows 10 or 11. Internet is needed for the initial installation; the installed study app works offline.

## Use it in your browser

In the installed app, open **Settings → Open in browser**. Both views use the same local records, screenshots and study tools. Keep the desktop app running while using its browser view.

Records stay on this computer. There is no cloud storage or automatic sync to another computer or phone. Each person has their own local records. Export backups to keep a separate copy.

## Updating an existing V10 installation

Export a backup, then use **Settings → Updates → Import app update** with the `.emtupdate` file from the latest release. This keeps the installation’s existing profile. Running a fresh installer creates an empty profile; existing profiles are preserved.

This repository contains downloads and release notes. The original application source and private update-signing key are not published here.
